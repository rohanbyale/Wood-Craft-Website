> 🧠 **Turn preparation into confidence.** An AI-powered platform that transforms resumes and job descriptions into personalized interview questions and smart preparation roadmaps.

## ✨ Core Features

- 🤖 AI-generated technical & behavioral interview questions
- 📄 Intelligent resume and job description analysis
- 🎯 Personalized, role-specific preparation roadmaps
- 🔐 Secure JWT authentication
- ⚡ RESTful APIs for seamless application integration

## 🛠️ Technical Powerhouse

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Frontend** | React.js | Interactive UI and component-based development |
| **Styling** | Tailwind CSS | Responsive, utility-first styling |
| **Animations** | Framer Motion | Smooth transitions and engaging interactions |
| **Icons** | Lucide React | Clean, lightweight SVG icons |
| **Routing** | React Router | Seamless client-side navigation |
| **Backend** | Node.js + Express.js | Server logic and REST APIs |
| **Database** | MongoDB | Flexible data persistence |
| **AI Engine** | Generative AI | Context-aware question generation |
| **Deployment** | Netlify | Frontend hosting |
